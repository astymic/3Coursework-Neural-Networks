## Розділ 1. Математика Штучного Нейрона та Персептрон Розенблата

### 1.1 Біологічне підґрунтя та Штучний Нейрон
Людський мозок складається з мільярдів нейронів. Кожен нейрон отримує сигнали через дендрити, обробляє їх у ядрі (сомі) і, якщо сумарний сигнал перевищує певний поріг, передає його далі через аксон до інших нейронів (через синапси).
Штучний нейрон (персептрон), запропонований Френком Розенблатом у 1957 році, працює за тим самим принципом.

**Математична модель штучного нейрона:**
1. **Входи (Inputs):** $x_1, x_2, ..., x_n$ (вектор $X$). Це можуть бути відтінки пікселів, ціни на житло, частоти звуку тощо.
2. **Ваги (Weights):** $w_1, w_2, ..., w_n$ (вектор $W$). Ваги визначають важливість кожного входу. Якщо на вході "рівень дощу", а ми прогнозуємо вартість акцій Apple, вага цього входу має бути близька до 0. Якщо ми прогнозуємо врожай, вага буде великою.
3. **Зміщення (Bias, $b$):** Спеціальний параметр, який дозволяє зсувати функцію активації вліво або вправо. Завдяки йому персептрон може розділяти дані, навіть якщо всі входи $X$ дорівнюють нулю.
4. **Агрегатор (Зважена сума):** $z = w_1x_1 + w_2x_2 + ... + w_nx_n + b = \sum_{i=1}^{n} w_ix_i + b$. У векторній формі: $z = W \cdot X + b$.
5. **Функція Активації (Activation Function, $f(z)$):** Перетворює зважену суму у вихідний сигнал. Для класичного персептрона використовується **Порогова функція Хевісайда**:
   - $y = 1$, якщо $z \ge 0$
   - $y = 0$, якщо $z < 0$

### 1.2 Навчання Персептрона (Дельта-правило)
Персептрон потрібно "навчити" — тобто підібрати правильні ваги $W$ та зміщення $b$.
Для цього йому дають тренувальні приклади з відомими правильними відповідями (Target, $d$).

**Алгоритм лінійного навчання (Gradient Descent / Дельта-правило):**
1. Ініціалізувати всі ваги та зміщення нулями або випадковими числами.
2. Подати на вхід приклад $X$.
3. Отримати прогноз $y = f(W \cdot X + b)$.
4. Обчислити похибку: $Error = d - y$ (де $d$ — правильна відповідь).
5. Якщо $Error \neq 0$, оновити ваги за формулою:
   $w_i^{(new)} = w_i^{(old)} + \eta \cdot Error \cdot x_i$
   $b^{(new)} = b^{(old)} + \eta \cdot Error$
   Де **$\eta$ (Learning Rate)** — швидкість навчання (зазвичай від 0.01 до 0.1). Якщо взяти завеликий $\eta$, ваги розхитаються, і алгоритм ніколи не знайде мінімум.

### 1.3 Обмеження Лінійної Роздільності та проблема XOR
Персептрон — це лінійний класифікатор. У двовимірному просторі $z = w_1x_1 + w_2x_2 + b = 0$ є рівнянням прямої лінії. Отже, персептрон просто проводить одну пряму, яка ділить простір на нулі та одиниці (Клас 0 та Клас 1).

**Проблема логічного XOR (Виключне АБО):**
- $x=(0,0) \to 0$
- $x=(0,1) \to 1$
- $x=(1,0) \to 1$
- $x=(1,1) \to 0$
Якщо ви намалюєте ці точки на листку паперу (клас 1 і клас 0), ви побачите, що **неможливо провести одну пряму лінію**, яка б відділила всі нулі від одиниць. Саме тому один персептрон ніколи не зможе вивчити правило XOR. Для цього потрібні Багатошарові Мережі.

### 1.4 Практичний код (ЛР1: Навчання логічного AND)
```python
import numpy as np

class Perceptron:
    def __init__(self, input_size, lr=0.1, epochs=10):
        self.W = np.zeros(input_size + 1) # Додаткова вага для Bias (b)
        self.epochs = epochs
        self.lr = lr
    
    def predict(self, x):
        # Додаємо x_0 = 1 до вектора X, щоб множити його на вагу Bias (w_0)
        x_with_bias = np.insert(x, 0, 1)
        z = np.dot(self.W, x_with_bias)
        return 1 if z >= 0 else 0
 
    def fit(self, X, d):
        for epoch in range(self.epochs):
            total_error = 0
            for i in range(len(d)):
                y = self.predict(X[i])
                error = d[i] - y # Якщо y правильний, error = 0.
                if error != 0:
                    x_with_bias = np.insert(X[i], 0, 1)
                    # Оновлення ваг (Дельта правило)
                    self.W += self.lr * error * x_with_bias
                    total_error += abs(error)
            print(f"Epoch {epoch+1}, Error: {total_error}")

# Дані для логічного AND
X_train = np.array([[0,0], [0,1], [1,0], [1,1]])
y_train = np.array([0, 0, 0, 1])

p = Perceptron(input_size=2)
p.fit(X_train, y_train)

# Перевірка (Inference)
print(f"[1, 1] AND -> {p.predict(np.array([1, 1]))} (Expected: 1)")
print(f"[1, 0] AND -> {p.predict(np.array([1, 0]))} (Expected: 0)")
```

## Розділ 2. Багатошарові Мережі (MLP) та Глибоке Навчання (Deep Learning)

### 2.1 Архітектура Multi-Layer Perceptron (MLP)
Щоб вирішити нелінійні проблеми (як XOR або розпізнавання картинок), нейрони об'єднують в шари. Мережа стає універсальним апроксиматором функцій.
- **Вхідний шар (Input Layer):** Просто отримує дані.
- **Приховані шари (Hidden Layers):** Можуть складатися з десятків чи тисяч нейронів. Кожен нейрон у шарі з'єднаний з усіма нейронами попереднього та наступного шару (Fully Connected / Dense layers). 
- **Вихідний шар (Output Layer):** Дає остаточний результат (вектор градієнтів, ймовірності, класи).

### 2.2 Нелінійні Функції Активації
Якщо ми будемо з'єднувати лінійні рівняння (з персептрона) одне за одним, вся наша 100-шарова мережа математично стиснеться до одного лінійного рівняння: $f(f(f(x))) = w(w(w x))) = w'x$. Щоб мережа могла гнути простір і будувати нелінійні межі, кожен нейрон повинен мати **нелінійну функцію активації**:
1. **Sigmoid $\sigma(x) = \frac{1}{1 + e^{-x}}$:** Тисне всі числа в діапазон від 0 до 1. Мінуси: якщо вхід занадто великий або малий (>5 чи <-5), функція стає майже плоскою (похідна = 0). Градієнт затухає, нейрони вмирають і мережа припиняє вчитись.
2. **Tanh (Гіперболічний тангенс):** Традиційний для рекурентних мереж (діапазон від -1 до 1). Також страждає на затухання градієнтів.
3. **ReLU (Rectified Linear Unit) $f(x) = \max(0, x)$:** **Золотий стандарт сьогодні**. Якщо число від'ємне — дає 0. Якщо позитивне — дає те саме число. Переваги: не затухає (похідна для $x>0$ завжди дорівнює 1), обчислюється неймовірно швидко (без експонент).

### 2.3 Навчання: Зворотне поширення помилки (Backpropagation)
Як налаштувати 1 мільярд ваг у глибокій мережі? Нам потрібен градієнтний спуск (Gradient Descent - оптимізатор) в комбінації з Backpropagation.
1. Мережа робить рандомний прогноз. Рахується **Функція Втрат (Loss Function):** наскільки ми далекі від ідеалу (наприклад, Mean Squared Error або Cross-Entropy).
2. Щоб зрозуміти, яку саме з мільярда ваг куди потягнути, алгоритм шукає **Частинну Похідну (Partial Derivative)** функції Loss по відношенню до кожної ваги $w_{ij}$. 
3. *Backprop* використовує ланцюгове правило похідних з математичного аналізу (Chain Rule), рахуючи похибку вихідного шару, потім передаючи залишок похибки прихованому шару і так аж до самого початку.
4. Оптимізатор (наприклад `Adam` або `SGD`) оновлює кожну вагу $w_{ij} = w_{ij} - \eta \frac{\partial Loss}{\partial w_{ij}}$.

### 2.4 Практичний код (ЛР2: Keras MLP)
```python
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Flatten

# Завантажуємо датасет зображень одягу (28х28 пікселів)
fashion_mnist = tf.keras.datasets.fashion_mnist
(train_images, train_labels), (test_images, test_labels) = fashion_mnist.load_data()

# Нормалізуємо пікселі: ділимо на 255. Мережі легше вчитися на числах [0, 1] або [-1, 1]
train_images = train_images / 255.0

# Створюємо архітектуру Feedforward Neural Network
model = Sequential([
    # Витягуємо матрицю 28x28 у вектор з 784 елементів (Input Layer)
    Flatten(input_shape=(28, 28)),
    
    # Hidden Layer 1: 128 нейронів, активація ReLU для запобігання затухаючого градієнта
    Dense(128, activation='relu'),
    
    # Вихідний шар: 10 нейронів (бо 10 типів одягу). 
    # Софтмакс гарантує, що сума всіх виходів = 1 (всі 10 виходів матимуть сенс ймовірностей: 80% футболка, 10% пальто тощо)
    Dense(10, activation='softmax')
])

# Компіляція
model.compile(optimizer='adam', # Adam динамічно підбирає learning_rate для кожної ваги 
              loss='sparse_categorical_crossentropy', # Loss для мультикласової класифікації
              metrics=['accuracy'])

# Навчання (Backpropagation робиться Keras під капотом за нас)
history = model.fit(train_images, train_labels, epochs=10)
```

## Розділ 3. Згорткові Нейронні Мережі (CNN / Здібність Бачити)

### 3.1 Чому не MLP? Просторовий контекст
Якщо ми сплющимо фотографію обличчя $1000 \times 1000$ пікселів у вектор в 1 мільйон елементів (`Flatten`), ми втратимо інформацію про те, що піксель ока знаходиться поруч із пікселем брови (бо у векторі вони можуть опинитися далеко від іншого).
Також для MLP знадобиться матриця розміром $1'000'000 \times 500$ для першого шару (півмільярда ваг!). Забагато навіть для суперкомп'ютерів.

### 3.2 Згортка (Convolution)
CNN працюють шляхом застосування **Фільтрів (Kernels)**. Фільтр — це крихітна матриця ваг (наприклад, $3\times3$). Він ковзає поверх оригінального зображення крок за кроком (stride = 1), перемножуючи свої значення на значення пікселів.
*Результат* — Нова оптимізована матриця (Feature Map).
- Фільтр №1 може автоматично вивчити шаблон (ваги), який реагує на вертикальні лінії.
- Фільтр №2 буде "світитися" при знаходженні круглих форм (очей).

**Чому це ефективно (Weight Sharing)?** Оскільки один фільтр $3\times3$ шукає горизонтальні лінії **усюди** по всьому зображенню, йому треба всього 9 ваг, а не 1 мільйон.

### 3.3 MaxPooling (Зменшення розмірності)
Після кожної операції `Conv2D` зазвичай застосовують `MaxPooling2D`. Вона бере "віконце" $2\times2$ і викидає три пікселі, залишаючи лише один — з максимальним числом (той, де фільтр "спрацював" найкраще).
Це дає дві суперздібності:
1. Зображення зменшується в 4 рази (вдвічі по ширині і вдвічі по висоті), тому наступним шарам набагато швидше обробляти інформацію (збереження VRAM на GPU).
2. **Translation Invariance:** Якщо межа предмета зсунеться на пару пікселів, MaxPooling все одно вихопить її максимум і передасть далі. Фотографія може бути трішки "зіпсованою" або "змазаною", мережі буде байдуже.

### 3.4 Практичний код (ЛР3: Архітектура LeNet/VGG стилю)
```python
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense

def create_cnn():
    model = Sequential([
        # Вхідний тензор: 28x28 пікселів, 1 канал (чорно-білий. Для кольорових: 3 канали RGB)
        # Згортка використовує 64 фільтри 3x3. padding='same' додає чорні нулі по краях (щоб не втрачати розмір).
        Conv2D(64, (3, 3), activation='relu', input_shape=(28, 28, 1), padding='same'),
        
        # MaxPooling (Шар стиснення / Pool) зменшує просторову вимірність до 14х14
        MaxPooling2D((2, 2)),
        
        # Наступний шар згортки. Більше фільтрів (128), бо картинка менша, але ознаки складніші (вуха, ніс, цілі форми)
        Conv2D(128, (3, 3), activation='relu', padding='same'),
        MaxPooling2D((2, 2)), # Зменшує просторову вимірність до 7х7
        
        # Після виділення всіх 2D супер-ознак ми можемо їх розплющити.
        Flatten(),
        
        # Dense (Fully-Connected) шар приймає рішення "Ага, багато ліній під 45 градусів і два кола -> це цифра 8"
        Dense(256, activation='relu'),
        Dense(10, activation='softmax')
    ])
    return model
```

## Розділ 4. Рекурентні Нейронні Мережі (RNN) та Час

### 4.1 Суть Рекурентності
Обычні мережі (MLP, CNN) є *Безпам'ятними/Stateless*. Коли вони обробляють кадр №2 з відео, вони повністю забули кадр №1. Для NLP (Обробка Природної Мови), перекладу, генерації тексту або аудіо це не працює: слово "він" в кінці речення залежить від імені Петя на початку речення.

**RNN (Recurrent Neural Networks)** мають стан (State), який постійно оновлюється під час проходження по послідовності.
На кожному часовому кроці (Time Step) $t$ рівняння таке:
$h_t = f_w(h_{t-1}, x_t)$
Дані оновлюються: $h_t = \tanh(W_{hh} \cdot h_{t-1} + W_{xh} \cdot x_t + b_h)$.
Тобто, нейрон помножує своє минуле $h_{t-1}$ на матрицю $W_{hh}$, а нове слово $x_t$ на $W_{xh}$, складає їх і проганяє через $\tanh$.

### 4.2 Прокляття RNN: Vanishing та Exploding Gradients
Коли ми робимо Backpropagation (Зворотне поширення), щоб виправити помилку в слові №100, нам потрібно розрахувати похідну $h_{100}$ по відношенню до $h_{1}$. З математичної точки зору, нам треба 100 разів помножити градієнт на матрицю пам'яті $W_{hh}$.
- Якщо значення у вагах матриці $W_{hh}$ менші за 1 (наприклад 0.9), то $0.9^{100} = 0.00002$. Градієнт "затухає", і мережа не може вивчити довгострокову залежність (Vanishing).
- Якщо ваги трохи більші за 1 (наприклад 1.1), то $1.1^{100} = 13780$. Градієнт **вибухає**, значення ваг стає `NaN`, і мережа крашиться (Exploding Gradients).

**Як цього уникають?**
- З *Exploding* борються за допомогою **Gradient Clipping** - якщо градієнт перевищує 1, ми примусово обрізаємо його до 1 перед оновленням ваги.
- З *Vanishing* борються складно — базову RNN замінюють на більш розумні архітектури, такі як **LSTM (Long Short-Term Memory)** або **GRU**. Вони мають внутрішні "Ворітця (Gates)", які вирішують, яку пам'ять стерти, а яку записати без нескінченного множення градієнтів.

### 4.3 Практичний код (ЛР4: RNN "з Нуля" на Numpy)
```python
import numpy as np

# Припустимо, ми класифікуємо фразу з 4 слів.
# Input: x_1, x_2, x_3, x_4. Кожне x_i — вектор 20 вимірів (One-Hot).

class VanillaRNN:
    def __init__(self, vocab_size, hidden_size):
        self.Whx = np.random.randn(hidden_size, vocab_size) * 0.01
        self.Whh = np.random.randn(hidden_size, hidden_size) * 0.01
        self.Why = np.random.randn(1, hidden_size) * 0.01
        self.bh = np.zeros((hidden_size, 1))
        self.by = np.zeros((1, 1))

    # Прямий прохід
    def forward(self, phrase_vectors):
        self.hs = {} 
        self.hs[-1] = np.zeros((self.Whh.shape[0], 1)) # Стартовий "порожній" стан
        
        for t, x in enumerate(phrase_vectors):
            self.hs[t] = np.tanh(np.dot(self.Whx, x) + np.dot(self.Whh, self.hs[t-1]) + self.bh)
            
        # Після 4 слів випльовуємо результат
        last_h = self.hs[len(phrase_vectors)-1]
        y = np.dot(self.Why, last_h) + self.by
        # Sigmoid для класифікації
        return 1 / (1 + np.exp(-y))

    # Backpropagation Through Time (BPTT)
    def bptt(self, d_y, phrase_vectors, learning_rate):
        d_Whx, d_Whh, d_bh = np.zeros_like(self.Whx), np.zeros_like(self.Whh), np.zeros_like(self.bh)
        
        # d_h (градієнт від вихідного шару)
        d_h = np.dot(self.Why.T, d_y)
        
        # Від останнього слова до першого
        for t in reversed(range(len(phrase_vectors))):
            # Похідна tanh
            temp = (1 - self.hs[t] ** 2) * d_h
            
            d_bh += temp
            d_Whh += np.dot(temp, self.hs[t-1].T)
            d_Whx += np.dot(temp, phrase_vectors[t].T)
            
            # Передаємо градієнт назад у часі!
            d_h = np.dot(self.Whh.T, temp)

        # ВИРІШЕННЯ EXPLODING GRADIENTS: Gradient Clipping!
        for d in [d_Whx, d_Whh, d_bh]:
            np.clip(d, -1, 1, out=d) 

        # Оновлення ваг 
        self.Whx -= learning_rate * d_Whx
        self.Whh -= learning_rate * d_Whh
```

## Розділ 5. Кластеризація та Навчання без Вчителя (Unsupervised Learning)

### 5.1 Чим Unsupervised відрізняється від Supervised?
Усі попередні мережі (MLP, CNN, RNN) були Supervised (з учителем). У нас були картинки `X` і ми точно знали, що це кіт `y`.
У задачах кластеризації у нас є лише `X` (наприклад, база покупок клієнтів), і нам треба розбити їх на сегменти (групи). Ми не знаємо правильних відповідей.

### 5.2 K-Means (Метод k-середніх)
Алгоритм працює з евклідовою відстанню.
1. Ми кажемо $k=3$ (Хочемо 3 кластери).
2. Алгоритм кидає в простір 3 рандомні точки (Центроїди).
3. Кожен рядок бази даних ($X_i$) дивиться, до якого центроїда йому ближче, і фарбується в його колір.
4. Ми шукаємо центр мас зелених точок, і пересуваємо зелений центроїд туди. 
5. Повторювати, поки центроїди не перестануть рухатись.
**Проблеми:** Перевіряє лише відстань. Якщо кластер має форму півмісяця, k-means розріже його навпіл (бо алгоритм шукає "кулі").

### 5.3 DBSCAN (Density-Based Spatial Clustering)
Кластеризація *за щільністю*.
Вам не треба задавати $k$ кластерів! Ви задаєте:
- `eps` - радіус околу (наприклад, 2 метри).
- `min_samples` - скільки точок має бути в радіусі, щоб створити "Ядро (Core Point)".
Алгоритм йде по точках. Якщо точка має багатьох сусідів, вони утворюють кластер (який може згинатися як завгодно).
Якщо точка висить одна в порожнечі і поруч нікого немає — алгоритм позначає її як Шум (Noise / Outlier). Це ідеально для пошуку аномалій.

### 5.4 t-SNE та PCA (Зниження розмірності)
Якщо клієнт має 100 характеристик (вік, стать, зарплата, історія 97 покупок) — його вектор знаходиться у 100-вимірному гіперпросторі. Людина може бачити лише 3D.
- **PCA (Метод головних компонент):** Знаходить лінійні осі найбільшої дисперсії. Матрична математика стискає $100d$ у $2d$, але зі втратою складної нелінійної структури.
- **t-SNE (t-Distributed Stochastic Neighbor Embedding):** Дуже потужний імовірнісний алгоритм. Він намагається зберегти *локальні* відстані (щоб точки, які були поруч у 100D, обов'язково лишилися поруч у 2D/3D). З допомогою t-SNE можна візуалізувати навіть 784-вимірні картинки MNIST в 3D просторі для ідеального кластеризування кольорами.

### 5.5 Практичний код (ЛР5: scikit-learn Clustering)
```python
from sklearn.cluster import DBSCAN
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE

# X - набір даних з 100 ознак
# X_labels - реальні Y (імена кластерів для перевірки)

# 1. DBSCAN для пошуку аномалій
# EPS занадто малий - все буде шумом (-1). Занадто великий - все буде одним кластером. Гіпертюнінг є складним.
dbscan = DBSCAN(eps=0.5, min_samples=5)
clusters = dbscan.fit_predict(X) 
# Точки, де clusters == -1, варто видалити з бази або вивчити окремо (це шахраї або помилки)

# 2. t-SNE для візуалізації (4D -> 3D)
tsne = TSNE(n_components=3, perplexity=30)
X_3d = tsne.fit_transform(X)

# 3. PCA для зниження розмірності "важких" даних до 2 осей
pca = PCA(n_components=2)
X_2d = pca.fit_transform(X) # Ми втратимо трохи інформації, але збережемо загальну дисперсію
```
