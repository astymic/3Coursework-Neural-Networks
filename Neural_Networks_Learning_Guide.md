## Розділ 1. Одношаровий Персептрон (Основи)

### 1.1 Теорія
**Персептрон** — це найпростіша математична модель штучного нейрона. Він здатен розв'язувати задачі **лінійної класифікації** (коли об'єкти двох класів можна розділити на графіку прямою лінією).

**Принцип роботи:**
1. Отримує вхідні сигнали вектора $X = (x_1, x_2, ..., x_n)$.
2. Кожен сигнал має власну вагу (важливість) $W = (w_1, w_2, ..., w_n)$.
3. Сума за правилом: $z = w_1x_1 + w_2x_2 ... + b$, де $b$ (bias) — поріг зміщення.
4. Значення $z$ передається у **функцію активації** (найчастіше — порогову функцію Хевісайда $f(x) = 1$ якщо $x > 0$, інакше $0$).

**Обмеження:**
Персептрон **не в змозі** вирішити проблему логічного "Виключного АБО" (`XOR`), оскільки ці дані лінійно нероздільні. Це довів Марвін Мінський ще у 1969 році.

### 1.2 Приклад Коду (Numpy)
```python
import numpy as np

class Perceptron:
    def __init__(self, input_size, lr=0.1, epochs=100):
        # Ініціалізація ваг нулями, lr - learning rate (швидкість навчання)
        self.W = np.zeros(input_size + 1)
        self.epochs = epochs
        self.lr = lr
    
    def activation_fn(self, x):
        return 1 if x >= 0 else 0
 
    def predict(self, x):
        # Додаємо bias (одиницю) як перший елемент
        x = np.insert(x, 0, 1)
        z = np.dot(self.W, x)
        return self.activation_fn(z)
 
    def fit(self, X, d):
        for epoch in range(self.epochs):
            for i in range(len(d)):
                y = self.predict(X[i])
                error = d[i] - y
                # Оновлення ваги лише тоді, коли є помилка
                if error != 0:
                    x_i = np.insert(X[i], 0, 1)
                    self.W += self.lr * error * x_i

# Тренування логічного АНД (AND)
X = np.array([[0,0], [0,1], [1,0], [1,1]])
d = np.array([0, 0, 0, 1]) # Очікуваний результат

p = Perceptron(input_size=2)
p.fit(X, d)

print(f"Prediction for [1,1]: {p.predict(np.array([1, 1]))}") # Output: 1
```

## Розділ 2. Багатошарові Мережі Прямого Поширення (MLP / Feedforward)

### 2.1 Теорія
Щоб вирішувати складні, нелінійні задачі, були створені **Багатошарові персептрони (MLP)**.
- **Архітектура:** Input Layer -> (N) Hidden Layers -> Output Layer. Зв'язки направлені виключно вперед.
- **Функція Активації (Hidden):** `Sigmoid` (0 до 1), `Tanh` (-1 до 1), `ReLU` (max(0, x)). `ReLU` є стандартом, оскільки вона не піддається затуханню градієнтів на відміну від сигмоїди.
- **Алгоритм навчання:** Backpropagation (Зворотне поширення). Мережа "дивиться", наскільки її $y$ відрізняється від очікуваного $d$ (знаходить Loss). Потім, за допомогою правила ланцюга (Chain Rule з математики похідних), вона з кінця до початку коригує кожну вагу за напрямком градієнта.

### 2.2 Приклад Коду (TensorFlow / Keras)
Створення простого MLP для класифікації рукописних цифр (MNIST).
```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Flatten

def build_mlp():
    model = Sequential([
        # Вирівнюємо зображення 28х28 в одномірний масив 784
        Flatten(input_shape=(28, 28, 1)),
        # Перший прихований шар, 128 нейронів, активація ReLU
        Dense(128, activation='relu'),
        # Другий прихований шар, 64 нейрони
        Dense(64, activation='relu'),
        # Вихідний шар (10 класів від 0 до 9), функція softmax для ймовірностей
        Dense(10, activation='softmax')
    ])
    
    # sparse_categorical_crossentropy використовується, коли класи не One-hot (а просто 0, 1, 2)
    model.compile(optimizer='adam',
                  loss='sparse_categorical_crossentropy',
                  metrics=['accuracy'])
    return model

model = build_mlp()
# Далі: model.fit(x_train, y_train, epochs=5)
```

## Розділ 3. Згорткові Нейронні Мережі (CNN)

### 3.1 Теорія
Класичний MLP розплющує зображення в одномірний вектор, втрачаючи 2D-зв'язки між пікселями (якщо око зліва і око справа — MLP не зрозуміє, що це обличчя).
**CNN** (Convolutional Neural Networks) ідеальні для Computer Vision.
- **Conv2D (Згортка):** Основний шар. "Матриця-фільтр" (ядро) ковзає поверх пікселів і перемножує їх: $FeatureMap = Activation(Kernel * Image)$. Вона шукає границі, текстури, кути. В процесі тренування мережа сама "вчить" фільтри шукати корисні патерни.
- **MaxPooling2D:** Шар "стиснення". Бере матрицю, розбиває на квадрати 2х2 і зберігає лише найвище значення (найяскравішу межу), відкидаючи інші. Це експоненційно зменшує кількість розрахунків і додає $Space Invariance$ (якщо кіт зміститься вбік на фото, мережа все одно його розпізнає).

### 3.2 Приклад Коду (Keras / GPU-Ready CNN)
```python
from tensorflow.keras.layers import Conv2D, MaxPooling2D

def build_cnn():
    model = Sequential([
        # Згортковий шар: 32 фільтри розміром 3х3
        Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)),
        # MaxPooling зменшує картинку з 26х26 на 13х13
        MaxPooling2D((2, 2)),
        
        # Ще глибший шар для більш складних ознак
        Conv2D(64, (3, 3), activation='relu'),
        MaxPooling2D((2, 2)),
        
        # Наприкінці завжди йде Flatten() і Dense() як в MLP
        Flatten(),
        Dense(64, activation='relu'),
        Dense(10, activation='softmax')
    ])
    return model
```

## Розділ 4. Рекурентні Нейронні Мережі (RNN)

### 4.1 Теорія
RNN створенні для роботи з "послідовностями" (Sequence Data) — текстами, аудіо, часовими рядами акцій на біржах.
На відміну від MLP, RNN мають **цикл**: нейрон отримує не лише новий вхід $X_t$, але й свою пам'ять з минулого кроку $H_{t-1}$.
Формула: $H_t = \tanh(W_{hx} X_t + W_{hh} H_{t-1} + b)$

**Проблема BPTT та Вибухаючих Градієнтів:**
Коли ми робимо Backprop через сотні слів тексту (кроків у часі), ми множимо градієнт на матрицю ваг $W_{hh}$ багато разів:
- Якщо $W < 1$, градієнт затухне (мережі важко "пам'ятати" початок речення).
- Якщо $W > 1$, градієнт **вибухне** в безкінечність (NaN/Overflow). Останнє лікується методом **Gradient Clipping**.

### 4.2 Приклад Коду: Gradient Clipping на чистому Numpy
```python
import numpy as np

# Прямий прохід
def rnn_forward(inputs, Whx, Whh, bh):
    h = np.zeros((Whh.shape[0], 1)) # Стартова пам'ять
    for t in range(len(inputs)):
        # Важливо використовувати tanh для утримання сигналу в межах [-1, 1]
        h = np.tanh(np.dot(Whx, inputs[t]) + np.dot(Whh, h) + bh)
    return h

# Демонстрація лікування Explosive Gradients (Clipping)
def clip_gradients(d_Whx, d_Whh):
    np.clip(d_Whx, -1, 1, out=d_Whx)
    np.clip(d_Whh, -1, 1, out=d_Whh)
    return d_Whx, d_Whh

# (Повний код BPTT "з нуля" займає ~100 рядків і реалізований в нашому Lab4_RNN.py)
```

## Розділ 5. Machine Learning (Навчання без Вчителя: Кластеризація)

### 5.1 Теорія
У цих моделях немає $y$ (правильних відповідей). Система шукає закономірності самостійно у векторі $X$.
1. **K-Means (Метричний):** 
   - Випадково встановлює $k$ "центрів" кластерів (Centroids).
   - Присвоює кожній точці найближчий центроїд.
   - Зсуває центроїд в центр ваги точок. Повторює до зупинки. Найкраще працює для круглих/еліпсоїдних форм кластерів.
2. **Agglomerative (Ієрархічний):**
   - Кожна точка стартує як свій власний кластер.
   - На кожному кроці алгоритм зліплює дві "найближчі" точки у більший кластер (часто через мінімізацію дисперсії по методу *Ward*). 
   - Утворюється графікове дерево — **Дендрограма**.
3. **DBSCAN (Density-based):**
   - Шукає густі "згустки" даних. Працює краще для кластерів неправильної форми (вісімка лежить в колі). Все, що в порожнечі, оголошується "Шумом" (Outliers, Label: -1).

### 5.2 Приклад Коду (scikit-learn)
```python
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans, DBSCAN
from sklearn.datasets import load_iris

# Дані (Кількості вчителів не використовуються!)
X = load_iris().data

# --- K-Means ---
# Ініціалізація k-means для 3 кластерів (так як ми знаємо, що ірисів 3 типи)
kmeans = KMeans(n_clusters=3, random_state=42)
k_labels = kmeans.fit_predict(X)

# --- DBSCAN ---
# eps - максимальна відстань між двома точками, щоб вони вважались "сусідями"
# min_samples - скільки мінімум треба сусідів, щоб утворити кластер
dbscan = DBSCAN(eps=0.5, min_samples=5)
d_labels = dbscan.fit_predict(X)

# Якщо d_labels == -1, це точка-викид (Шум/Аномалія).
```
