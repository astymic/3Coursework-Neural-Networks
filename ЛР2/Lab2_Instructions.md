# Лабораторна робота №2: Багатошаровий перцептрон (MNIST та Fashion MNIST)

**Мета:** Написати програму мовою Python, що створює та навчає нейронну мережу для розпізнавання рукописних цифр (MNIST) та графічних символів (Fashion MNIST) за допомогою NumPy.

## Завдання
1. **Базовий приклад:** Вивчіть алгоритм та роботу базової програми `Network1` (з методички). Введіть код розглянутого прикладу та отримайте результат її роботи на базі MNIST. **Для завантаження даних використовуйте завантажений файл `mnist.pkl.gz` замість бібліотеки keras.**
2. **Fashion MNIST:** Ознайомтеся самостійно з бібліотекою Fashion MNIST.
3. **Модифікація мережі:** Створіть аналогічну програму `Network2` для розпізнавання набору даних **Fashion MNIST** з використанням активаційної функції **ReLU**. 
   * *Зауваження:* При використанні ReLU треба змінити не тільки саму функцію та її похідну, але й відповідно переробити метод `backprop` (зворотне поширення помилки).
   * Змінюючи гіперпараметри, домагайтеся мінімізації помилки розпізнавання.
4. **Тестування та Візуалізація:** Після завершення навчання мережі продемонструйте її роботу на **двох довільно вибраних прикладах** зображень бібліотеки Fashion MNIST. 
   * Створіть програму рандомного вибору прикладів з бібліотеки.
   * Подайте їх на вхід мережі та отримайте результат класифікації.
   * Зробіть процедуру **візуалізації** цих двох обраних зображень.
5. **Аналіз:** Порівняйте результати роботи двох мереж (`Network1` на сигмоїді та `Network2` на ReLU), зробіть висновки щодо якості їх роботи з різними активаційними функціями.

## Зміст звіту
- Коди програми `Network2` із коментарями.
- Скріншоти з результатами навчання створеної мережі для Fashion MNIST.
- Скріншоти з результатами класифікації (і візуалізації) двох вибраних прикладів.
- Висновки.
