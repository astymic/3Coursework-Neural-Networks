# Інтеграційний План Курсової Роботи: Штучні Нейронні Мережі

Цей документ описує структуру виконаного університетського проєкту з дисципліни "Штучні Нейронні Мережі".
Оскільки було прийнято рішення відмовитися від первісної ідеї інтеграції ШІ для HR-команди, цей проєкт фокусується виключно на поглибленому вивченні та практичній імплементації різних архітектур штучних нейронних мереж згідно з лабораторними методичними вказівками.

## Огляд Проєкту
Проєкт складається з 5 послідовних лабораторних робіт, які охоплюють еволюцію нейронних мереж від найпростішого персептрона до сучасних методів кластеризації. 

### Технологічний Стек
- **Мова програмування:** Python 3.10+
- **Бібліотеки глибокого навчання:** TensorFlow 2.10, Keras (з підтримкою виконання на GPU через `tensorflow-directml`).
- **Математика та обробка даних:** NumPy, Pandas.
- **Машинне навчання (Класичне):** scikit-learn.
- **Візуалізація:** Matplotlib.

---

## Структура Виконаних Робіт

### Лабораторна Робота №1: Одношаровий Персептрон
- **Завдання:** Створення та навчання одношарового персептрона "з нуля" без використання високорівневих фреймворків.
- **Особливості:** Бінарна класифікація даних (логічні функції або лінійно-роздільні вибірки) за допомогою бібліотеки `numpy`.
- **Результат:** Звіт, код персептрона та графіки похибки під час навчання.

### Лабораторна Робота №2: Багатошарові Мережі Прямого Поширення (Feedforward)
- **Завдання:** Використання бібліотеки `Keras` для створення мереж з кількома прихованими шарами.
- **Особливості:** 
  - Network 1: Класифікація рукописних цифр MNIST з використанням функції активації `Sigmoid`.
  - Network 2: Класифікація одягу Fashion MNIST з використанням `ReLU` та оптимізатора `Adam`.
- **Результат:** Навчені моделі, візуалізація передбачень на тестових зображеннях.

### Лабораторна Робота №3: Згорткові Нейронні Мережі (CNN)
- **Завдання:** Побудова CNN для розпізнавання візуальних паттернів.
- **Особливості:** Використання шарів `Conv2D` та `MaxPooling2D`. Модель оптимізована під виконання на відеокарті (GPU) з використанням `tensorflow-directml`. Гіперпараметри включають `sgd` оптимізатор та `mean_squared_error` функцію втрат.
- **Результат:** Суттєве покращення точності розпізнавання MNIST у порівнянні з класичним MLP, графіки швидкості навчання на GPU.

### Лабораторна Робота №4: Рекурентні Нейронні Мережі (RNN)
- **Завдання:** Класифікація послідовностей (тексту) на основі власного датасету "технічних та ліричних фраз".
- **Особливості:** Реалізація згенерованої моделі RNN повністю "з нуля" на `numpy`. Застосування алгоритму зворотного поширення помилки через час (BPTT) з використанням "Gradient Clipping" для боротьби з вибухаючими градієнтами.
- **Результат:** Мережа, яка успішно (100% точність) класифікує короткі фрази за їх змістом.

### Лабораторна Робота №5: Навчання Без Вчителя (Кластеризація)
- **Завдання:** Пошук прихованих закономірностей у даних (на прикладі датасету Ірисів Фішера).
- **Особливості:** Практичне застосування кількох типів алгоритмів:
  1. `K-means` (Метричний підхід)
  2. `Agglomerative Clustering` (Ієрархічний підхід)
  3. `DBSCAN` + `PCA` (Кластеризація на основі щільності)
  4. `t-SNE` (Нелінійне зниження розмірності в 3D)
- **Результат:** Візуалізація результатів у форматах 2D Scatter, 3D Plot та побудова Дендрограми.
