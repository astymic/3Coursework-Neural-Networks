5.3. Оновлення ваги.  
Спочатку згадаємо трохи теорії. Коли перший розрахунок вихідних значень 
завершено, ми маємо вагові значення, згенеровані випадковим чином.  Але ці 
значення не дозволяють нам досягти правильної класифікації. Ми перетворюємо 
нейронну мережу на ефективну систему класифікації, багаторазово змінюючи 
ваги таким чином, щоб вони поступово відображали математичне 
співвідношення між вхідними даними та заданими вихідними значеннями. Зміна 
ваги досягається шляхом застосування наступного правила навчання для 
кожного рядка в навчальному наборі: 
 
wновий = w+(α×(вихідочикуваний − вихідрозрахований)×вхід) 
 
Символ α означає швидкість навчання.  Таким чином, щоб обчислити нове 
значення ваги, ми множимо відповідне вхідне значення на швидкість навчання і 
на різницю між очікуваним вихідним значенням (яке забезпечується навчальним 
набором) та розрахованим вихідним значенням, а потім результат цього 
множення додається до поточного значення ваги. Якщо ми визначимо дельту (δ) 
як (вихідочікуваний – вихідрозрахований), ми можемо переписати формулу як 
 
wновий=w+(α×δ×вхід) 
 
Тоді код процедури оновлення ваги (навчання) буде мати такий вигляд.

ΔW = error × input × Grad(output)        (1) 

--- Page 10 ---
 
Формула (1) дозволяє виконувати коригування ваги пропорційно до величини 
помилки (error). Далі множення відбувається на вхідне значення input. Якщо 
вхідне значення дорівнює 0, вага коригуватися не буде.  Потім виконується 
множення на градієнт сигмоїдної кривої (Grad (output)).  
Потрібно врахувати, що при великих числах крива має невеликий градієнт. 
Спрощено процес модифікації вагових коефіцієнтів можна описати так: якщо 
нейрон "впевнений" у правильності існуючої ваги, він "не хоче" коригувати його 
занадто сильно.  Множенням на градієнт кри вої саме це й досягається.  Для 
обчислення градієнта потрібно взяти похідну. У спрощеному вигляді це буде (2): 
 
Grad(output) = output× (1 – output)        (2) 
 
Якщо ми віднімемо 2-е рівняння з 1-го, то отримаємо необхідну підсумкову 
формулу: 
ΔW = error × input × output× (1 – output)

- array - для створення матриці; 
- random - для генерування випадкових чисел та ін.

for (x, y) in test_data]

Вхідні дані – x0, х1, … xn, а результати виводу – y0, y1, … yn. Дані xi та yi є векторами

Рекурентні нейронні мережі RNN працюють шляхом ітерованого оновлення

1. Поточний прихований стан ht обчислюється на основі попереднього ht - 1 та 
поточного входу xt; 
2. Поточний вихід yt обчислюється з урахуванням ht.

Рис. 1. Рекурентна нейронна мережа RNN "багато до багатьох"

 Whh використовується для всіх зв'язків  ht-1 → ht 
 Why використовується для всіх зв'язків  ht → yt 
Для рекурентної нейронної мережі ми також використовуємо два зміщення  (зсува):

2. Метод k-середніх 
Наибільш популярним алгоритмом кластеризації даних є метод k-середніх. Це 
ітеративний алгоритм кластеризації, що ґрунтується на мінімізації сумарних 
квадратичних відхилень точок кластерів від центроїдів (середніх координат) цих 
кластерів.  

--- Page 4 ---
Спочатку вибирається бажана кількість кластерів.  Оскільки нам відомо, що в 
нашому наборі даних є 3 класи, встановимо параметр моделі n_clusters, що 
дорівнює трьом.  
Далі, випадковим чином із вх ідних даних вибираються три елементи вибірки, 
яким у відповідність ставляться три кластери.  Тепер у кожен із кластерів буде 
включено по одній точці, кожна з яких буде центроїдом цього кластера. 
Далі шукаємо найближчого сусіда, поточного центроїду.  Додаємо точку до 
відповідного кластера та перераховуємо положення центроїду з урахуванням 
координат нових точок.  Алгоритм закінчує роботу, коли координати кожного 
центроїду перестають змінюватись. Центроїд кожного кластера в результаті є 
набором значень ознак, що описують усереднені параметри виділених класів.

3. Ієрархічна кластеризація 
Ієрархічна кластеризація, як випливає з назви, є алгоритм, який будує ієрархію

Метод t -SNE (англ. t -distributed stochastic neighbor embedding - розподілене 
стохастичне сусіднє вкладення) є одним із методів навчання без вчителя, що 
використовуються для візуалізації, наприклад, відображення простору високої 
розмірності в дво- або тривимірний простір.  
Метод відображає кожен об'єкт простору високої розмірності у дво - або 
трикоординатну точку таким чином, що близькі за характеристиками елементи 
даних у багатовимірному просторі (наприклад, датасеті з великим числом 
стовпців) проектуються в сусідні точки, а різнорідні об'єкти з більшою 
ймовірністю моделюються точками,  далеко віддаленими один від одного.  
Математичний опис роботи методу можна знайти  тут.

# Імпорт бібліотек 
from sklearn import datasets 
from sklearn.manifold import TSNE 
import matplotlib.pyplot as plt 
 
# Завантаження датасету 
iris_df = datasets.load_iris()  
 
# Визначаємо модель та швидкість навчання 
model = TSNE(learning_rate=100) 
 
# Навчаємо модель 
transformed = model.fit_transform(iris_df.data)  
 
# Представляємо результат у двовимірних координатах 
x_axis = transformed[:, 0] 
y_axis = transformed[:, 1] 
 
plt.scatter(x_axis, y_axis, c=iris_df.target)  
plt.show()

5. Метод кластеризації на основі щільності DBSCAN 
Метод DBSCAN (англ. Density-Based Spatial Clustering of Applications with Noise 
- алгоритм на основі щільності просторової кластеризації з присутністю шуму) є 

--- Page 9 ---
популярним алгоритмом кластеризації, який використовується при аналізі даних 
як одна з альтернатив методу k-середніх.  
Метод не вимагає попередніх припущень про кількість кластерів, але по трібно 
налаштувати два інші параметри: eps та min_samples. Дані параметри – це 
відповідно максимальна відстань між сусідніми точками та мінімальна кількість 
точок на околиці (кількість сусідів), коли можна говорити про те, що ці 
екземпляри даних утворюють один кластер. У бібліотеці scikit-learn є відповідні 
значення параметрів за замовчуванням (у розглянутому коді ці параметри взяті 
за замовчуванням), але, як правило, їх доводиться налаштовувати самостійно. 
# Імпортуємо бібліотеки 
from sklearn.datasets import load_iris 
import matplotlib.pyplot as plt 
from sklearn.cluster import DBSCAN 
from sklearn.decomposition import PCA 
 
# Завантажуємо датасет 
iris = load_iris() 
 
# Визначаємо модель 
dbscan = DBSCAN() 
 
# Навчаємо 
dbscan.fit(iris.data) 
 
# Зменшуємо розмірність за допомогою метода PCA - головних компонент 
pca = PCA(n_components= 2).fit(iris.data) 
pca_2d = pca.transform(iris.data)  
 
# Будуємо у відповідності до трьох класів 
for i in range(0, pca_2d.shape[0]): 
    if dbscan.labels_[i] == 0: 
        c1 = plt.scatter(pca_2d[i, 0], pca_2d[i, 1], c='r', marker='+') 
    elif dbscan.labels_[i] == 1: 
        c2 = plt.scatter(pca_2d[i, 0], pca_2d[i, 1], c='g', marker='o') 
    elif dbscan.labels_[i] == -1: 
        c3 = plt.scatter(pca_2d[i, 0], pca_2d[i, 1], c='b', marker='*') 
 
plt.legend([c1, c2, c3], ['Кластер 1', 'Кластер 2', 'Шум']) 
plt.title('DBSCAN знайшов 2 кластери та шум') 
plt.show()
