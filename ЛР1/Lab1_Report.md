# Звіт: Лабораторна робота №1

## 1. Архітектура мережі та гіперпараметри ШНМ
- **Тип мережі**: Одношаровий перцептрон (1 нейрон).
- **Кількість вхідних вузлів**: 3 (Дохід, Кредитний рейтинг, Відношення боргу до доходу).
- **Функція активації**: Сигмоїдна `σ(x) = 1 / (1 + e^(-x))`.
- **Швидкість навчання (Learning Rate)**: 0.05.
- **Початкові вагові коефіцієнти**: Згенеровані випадковим чином в інтервалі [0, 1].
- **Кількість епох навчання**: 10, 50, 100, 1000.

## 2. Алгоритм побудови навчальної та тестової вибірки
Вибірки були згенеровані через Python (`numpy.random.rand(num_samples)`), що одразу забезпечило їх **нормалізацію в межах [0, 1]**. 
Ми імітували параметри для кредитного скорингу банку:
- `Income_Norm` (Дохід)
- `CreditScore_Norm` (Кредитний рейтинг)
- `DTI_Ratio_Norm` (Борг до доходу - Debt-To-Income)

Вихідний результат (видати чи відхилити кредит) формувався за власною нелінійною функцією:
`output = 1, якщо (Income_Norm + CreditScore_Norm - DTI_Ratio_Norm) > 0.6`
В іншому випадку `output = 0`.
Було сформовано 500 прикладів для `train_data.xlsx` та 100 прикладів для `test_data.xlsx`.

## 3. Алгоритм навчання ШНМ
Навчання мережі здійснюється за **дельта-правилом** із використанням швидкості навчання та похідної сигмоїди:
Для кожної епохи, для кожного прикладу з навчальної вибірки:
1. Зчитується сума добутків входів на їх ваги: `sum = Σ (X[i] * W[i])`
2. Обчислюється результат активації: `output = sigmoid(sum)`
3. Обчислюється помилка: `error = Expected_Output - output`
4. Вектор ваг оновлюється за правилом: `ΔW[j] = learning_rate * error * X[i] * (output * (1 - output))`

## 6. Висновки
- Перцептрон з 1 нейроном зміг вивчити власну лінійну залежність навчального датасету і досяг **точності 86-87%** на перевірочному датасеті (тестовій вибірці).
- Сигнатура вагових коефіцієнтів повністю відповідає логіці нашої кастомної функції генерації `output`: ваги для `Income` та `CreditScore` є позитивними, а вага для `DTI_Ratio` — різко негативною. Нейромережа сама зрозуміла, що високий відсоток боргу впливає негативно на видачу кредиту.
- **Вплив кількості епох:** Після перших ~20-50 епох середня помилка різко падала. Далі мережа "довивчала" паттерни. Однак точність на тестовому сеті (86%) завмерла, незважаючи на падіння похибки на навчальному сеті (через неможливість 100% лінійної сепарації 3-мірного простору).
- Сигмоїдна функція дозволила зробити м'яке навчання ваг порівняно з жорсткою ступінчастою функцією, і показала чудову стабільність градієнту.
