# Лабораторна робота №5: Навчання без вчителя (Кластеризація)

**Мета:** Вивчити методи навчання без вчителя (k-means, ієрархічна кластеризація, t-SNE, DBSCAN) за допомогою scikit-learn.

## Завдання
1. **Метод k-середніх (k-means) - Аналіз:** Проаналізуйте, як розподіляються види ірисів (датасет Iris) при **інших комбінаціях параметрів/ознак** (у прикладі використовувались лише перші дві ознаки: sepal length та sepal width. Спробуйте інші пари).
2. **Візуалізація k-means:** Візуалізуйте отримані результати кластеризації.
3. **Ієрархічна кластеризація:** 
   * Здійсніть ієрархічну кластеризацію для датасету "Іриси Фішера".
   * Побудуйте дендрограму.
   * Порівняйте результати кластеризації двох методів (k-means та ієрархічної) для одного набору даних. 
   * Зробіть висновки: який метод краще підходить для великих наборів даних (час/обчислення) і чому; який точніший; який більш чутливий до шуму.
4. **Зниження розмірності (t-SNE):** Представте результат кластеризації t-SNE у **тривимірному (3D)** просторі. Порівняйте результати кластеризації датасету "Іриси Фішера" методами k-середніх та t-SNE, зробіть висновки.
5. **DBSCAN та PCA:** 
   * Вивчіть докладніше алгоритм DBSCAN і метод головних компонентів PCA.
   * Змініть параметри `eps` та `min_samples`, щоб досягти більш точної кластеризації розглянутого датасета. 
   * Зробіть висновки про роботу цього методу у порівнянні з методами, розглянутими раніше.

## Зміст звіту
- Коди написаних (змінених) алгоритмів із коментарями відповідно до завдань.
- Програми, що реалізують розглянуті методи.
- Візуалізація результатів роботи методів (графіки, 3D плоти, дендрограми).
- Висновки щодо кожного розділу лабораторної роботи.
